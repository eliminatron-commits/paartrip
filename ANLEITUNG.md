# Nhà Mình – PaarTrip: Anleitung für euch beide

Ein kleines Haus für genau zwei. Jeden Tag gibt es eine gemeinsame Aufgabe. Wenn ihr sie beide erledigt habt, kommt ein neues Stück ins Haus. Alle fünf Aufgaben erreicht ihr einen Meilenstein mit einem Geschenk.

Die App selbst ist auf Englisch.

## 1. App aufs iPhone holen (falls sie noch nicht da ist)

1. Öffne in **Safari** die Adresse `https://eliminatron-commits.github.io/paartrip/`. Andere Browser gehen nicht.
2. Tippe unten auf **Teilen** (das Quadrat mit dem Pfeil nach oben).
3. Wähle **Zum Home-Bildschirm** und dann **Hinzufügen**.
4. Öffne die App ab jetzt immer über das Symbol **PaarTrip** auf dem Home-Bildschirm, nicht über Safari.
   - Nur so funktionieren Mitteilungen.
   - Die App läuft auch ohne Netz.

## 2. Das Haus anlegen und einziehen

**Wichtig:** Alex legt das Haus an, seine Frau zieht mit dem Code ein. Die festen Gutscheine sind so verteilt.

**Alex:**
1. App öffnen und **Start our house** wählen.
2. Bei **Your first name** den Vornamen eintragen.
3. Auf **Open the door** tippen.
4. Die App zeigt einen Code (z. B. `ABCD-2345`). Gib ihn deiner Frau, per Nachricht oder vorgelesen. Der Code gilt nur einmal.

**Seine Frau:**
1. App öffnen und **I have a code** wählen.
2. Den Vornamen eintragen.
3. Bei **Code from your partner** den Code eintragen.
4. Auf **Move in** tippen.

Danach erscheint die erste Aufgabe unter **Today**.

## 3. Mitteilungen einschalten (jeder auf seinem iPhone)

1. Oben rechts auf das Zahnrad tippen. Das ist **Settings**.
2. Bei **Notifications** auf **Turn on notifications** tippen und die Frage des iPhones mit **Erlauben** beantworten.
3. Mit **Send a test** prüfen. Sperre das iPhone kurz, nach ein paar Sekunden kommt die Mitteilung.

Ihr bekommt dann eine Nachricht, wenn ihr an der Reihe seid oder ein Geschenk aufgeht. Morgens kommt ein Hinweis auf die neue Aufgabe. Es gibt keine Erinnerungen und kein Drängeln.

## 4. So spielt ihr

- **Today:** die Aufgabe des Tages. Es gibt drei Arten:
  - **Rätsel:** Jeder sieht nur seine Hälfte. Ihr löst es, indem ihr miteinander redet.
  - **Kennst du mich?** Beide antworten. Die Antworten werden erst aufgedeckt, wenn beide abgegeben haben.
  - **Echtes Leben:** eine kleine Sache außerhalb der App, zum Beispiel eine Sprachnachricht, ein altes Foto oder ein Lied. Einer macht sie für den anderen, manchmal macht ihr sie beide.
    - Wer etwas bekommen hat, tippt auf **It arrived**.
    - Wer es gemacht hat, sieht keinen Knopf. Die Aufgabe zählt, sobald der andere bestätigt.
- **Home:** euer Haus. Nach jeder Aufgabe wählt einer von euch ein Stück, der andere stellt es auf einen leuchtenden Platz. Stücke lassen sich später antippen und umstellen.
- **Gifts:** Hier stehen die Gutscheine. Ihr könnt auch selbst einen geheimen Gutschein hinterlegen.
  - Er öffnet sich an einem der nächsten Meilensteine. Die App zeigt, nach wie vielen Aufgaben.
  - Bis dahin sieht der andere nur ein verpacktes Geschenk von dir.
- Pro Tag kommt höchstens eine neue Aufgabe. Pausen sind kein Problem, es geht einfach dort weiter.
- Ein Punkt an einem Reiter zeigt, wo etwas auf dich wartet.
- Wartest du mit offener App auf den anderen, tippe oben auf den runden Pfeil links neben dem Zahnrad. Damit holst du seinen Schritt (**Refresh**).

## 5. Updates

- Gibt es eine neue Version, erscheint unten der Hinweis „New version“. Tippe dort auf **Update**, dann lädt die App neu.
- Von Hand prüfen: Settings → **Check for updates**.

## 6. Sicherung und neues iPhone

- Settings → **Save a backup file** speichert deinen Platz im Haus als Datei, z. B. in „Dateien“.
- Gib die Datei niemandem: Wer sie hat, kann in eurem Haus als du handeln.
- Auf einem neuen iPhone: App installieren und auf dem ersten Bildschirm **Restore from a backup file** wählen.

## 7. Wenn etwas hakt

- **„This phone isn't linked to the house anymore.“** Das Haus gibt es auf dem Server nicht mehr, zum Beispiel nach einem Neustart des Spiels.
  1. Auf **Start over** tippen, dann auf **Yes, start over**.
  2. Danach wie in Abschnitt 2 neu anlegen bzw. einziehen.
- **Keine Mitteilungen:**
  1. Prüfe, ob die App vom Home-Bildschirm aus geöffnet wurde.
  2. Schalte in Settings die Mitteilungen aus und wieder ein.
  3. Prüfe in den iPhone-Einstellungen unter **Mitteilungen → PaarTrip**, ob sie erlaubt sind.
- **Kein Ton:** Prüfe, ob in Settings → **Sound** der Ton an ist. Prüfe auch den Stummschalter und die Lautstärke des iPhones.
